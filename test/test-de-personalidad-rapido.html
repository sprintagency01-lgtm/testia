Qué es el TIPI

El Ten-Item Personality Inventory lo publicaron Gosling, Rentfrow y Swann en 2003 para medir los cinco grandes rasgos cuando no hay tiempo para un cuestionario largo. Usa dos frases por rasgo, una en cada sentido.

Cuándo usar un test corto o uno largo

El corto sirve para hacerte una idea general en un minuto. Si quieres un perfil más preciso de cada rasgo, el test de personalidad completo de 50 preguntas da una medida más fiable.

Fuentes y modelo de referencia

Sobre este test

Este test toma como referencia: TIPI (Gosling, Rentfrow & Swann, 2003). La redacción y la experiencia se han adaptado para uso divulgativo; el resultado no equivale a administrar el instrumento original en condiciones profesionales.

Aviso: Testia es una herramienta de entretenimiento y autoconocimiento. Los resultados son orientativos y no constituyen una evaluación ni un diagnóstico clínico.

Preguntas frecuentes

¿Es fiable un test de diez preguntas?

Para una visión general, sí: sus autores encontraron buena coincidencia con cuestionarios más largos. Para detalles finos, mejor el test completo.

¿Qué diferencia hay con el test completo?

Mide lo mismo, los cinco grandes, pero con menos precisión por rasgo.

¿Por qué solo dos frases por rasgo?

Para que sea muy rápido. Cada rasgo tiene una frase a favor y otra en contra para compensar respuestas automáticas.

¿Puedo repetirlo?

Sí. Es normal que el resultado varíe un poco de una vez a otra.
